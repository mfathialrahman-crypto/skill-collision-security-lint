# Security

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | yes |

## Reporting

Open a GitHub security advisory on this repository when the report contains a live secret. Otherwise open an issue titled `security:`.

Do not paste a live token into a public issue. Redact it first.

There is no paid bug bounty. Reports are still read.

## Scope

This repository is a static linter. A finding here is a pattern match, not proof of exploitability.
